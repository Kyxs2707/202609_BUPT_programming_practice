# **需求文档**

## 1. 需要完成的任务

1. 设计一个解释型的通用脚本语言，以MYB语言命名，并实现其解释器。MYB语言至少支持以下基本功能：
   - 整数，字符串等基本数据类型
   - 数组，结构类型
   - 基本输入输出
   - 分支循环控制
   - 函数定义和调用

    注意：MYB语言的语法可以自由定义，只要语义上要求即可，应该体现自己的特色，可以吸取各种语言的优点进行组合，但不能与现存的任何程序设计语言完全相同。

2. 编写MYB语言的完整黑盒测试集实现自动测试。测试脚本使用MYB语言编写，覆盖MYB语言的所有功能。一个命令执行所有测试。

3. 使用MYB语言设计一个用于性能测试的脚本进行性能测试，将测试结果与相同功能的python脚本的性能作比较。

4. 设计MYB语言的开发指南（例如Skills等文档）供编程Agent使用，使得编程Agent能够使用MYB语言顺利编写代码。

5. 使用编程Agent辅助，能够基于MYB语言快速设计实现一个代码规模不少于200行的应用程序（功能完整，内容不限制，例如可以是一个小游戏，小工具等）。

6. 实现解释器的程序设计语言没有限制

## 2.需要交付的内容

1. MYB语言的语法规则文档
2. 能够执行MYB语言的解释器源程序
3. MYB语言的完整黑盒测试集
4. 对MYB语言的性能测试报告
5. MYB语言的开发指南文档以及给AI使用的文档
6. 编程Agent使用MYB语言开发的应用程序源代码，编程Agent生成的开发记录
7. 所有工作的Git历史记录

## 3.评分标准

1. MYB解释器的实现（20分）
2. MYB解释器的自动测试脚本（20分）
3. MYB解释器的性能测试（10分）
4. MYB语言的语法说明，给人和AI使用的开发指南（20分）
5. 利用编程Agent，使用MYB语言开发程序（30分）
