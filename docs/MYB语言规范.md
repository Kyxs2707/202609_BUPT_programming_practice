# MYB 核心语言规范

版本：0.2，已确认的语言设计基线。整体确认日期：2026-10-19。

本文整理[语言设计讨论记录](./MYB语言设计讨论记录.md)中的 D01–D72，面向 MYB 程序员描述源码的合法形式、值与执行语义。用户于 2026-10-19 完成集中审阅并明确同意整份规范，本文作为后续工作的语言设计基线。示例结果均为阅读推导，尚无解释器执行证据；规范获批不表示功能已经实现。

本文不选择解释器宿主语言、前端工具、对象回收算法或平台后端，不定义 CLI、进程数值退出码或尚未确认的终端库接口。

## 1. 定位与程序组成

MYB 是小型、解释执行的通用脚本语言，源文件直接交给解释器运行。普通变量和函数形参动态绑定；结构字段显式声明类型并在创建、写入时检查。不引入全局静态类型分析。

源文件由顶层命名函数声明、命名结构声明和普通语句组成。函数与结构只能直接在文件顶层声明；独立块内不允许声明它们。解释器检查整个源文件的语法与结构，登记函数与结构并检查声明合法性，通过后按源码顺序执行顶层可执行语句。

函数预登记允许前向调用、自身递归及相互递归；结构预登记允许前向、自身和相互引用的字段类型。登记不执行函数体、不创建实例、不提前声明或初始化普通变量。

不要求 main 函数；名为 main 的函数也只有被显式调用才执行。执行到文件末尾正常结束。〔D01、D45、D52、D60、D68〕

## 2. 源码与词法

### 2.1 编码、名称与注释

- 源码采用 UTF-8，允许文件开头的 UTF-8 BOM，接受 CRLF、LF 等已确认的常见换行；无效编码报错。
- 空格、Tab 和换行分隔词法单元；缩进不决定代码块，换行不代替分号。
- 标识符为 `[A-Za-z_][A-Za-z0-9_]*`，区分大小写。字符串和注释可以包含中文、emoji，标识符首版不采用 Unicode 名称。
- 关键字为 `let fn struct if else while for in return break continue true false null`，不能作为自定义名称。
- 字符串之外的 `#` 开始单行注释，到当前行末尾结束。`//` 是整数除法。
- 函数、类型和内置名称受保护；不能被变量/参数声明遮蔽或通过赋值覆盖。结构字段有独立的名称集合，但仍须遵守标识符与关键字规则。

### 2.2 字符串字面量

单引号和双引号均产生 String，不提供独立字符类型。字面量不能直接跨行，支持以下转义：

| 写法 | 含义 |
|---|---|
| `\n`、`\r`、`\t` | 换行、回车、制表 |
| `\\`、`\"`、`\'` | 反斜杠、双引号、单引号 |
| `\u{HEX}` | 1～6 位十六进制数字表示的 Unicode 标量值 |

Unicode 标量须在 0..10FFFF 内，排除 D800..DFFF。未知转义、非法标量、未闭合字符串报错。字符串保存实际码点，不自动做 Unicode 规范化。

### 2.3 数字字面量

整数由十进制数字组成，前导零仍按十进制。浮点写法包括小数点两侧均有数字的小数，或带 e/E 指数的形式；指数可带正负号，必须有数字。

```text
0  42  007                    # Int64
0.5  1.0  1e3  3E-2  1.2e+4  # Float64
```

`.5`、`1.`、`1e`、`1e+`、`12abc` 报错；首版没有十六进制、二进制或数字分隔符。整数字面量越界不转浮点；必须能书写 `-9223372036854775808`，独立正数 `9223372036854775808` 非法。

Int64 最小值的直接负号例外：一元负号的操作数本身是十进制整数 token、没有中间分组或访问后缀时，幅值 9223372036854775808 可形成最小值；正常空白/注释可以分隔负号和数字，数字 token 本身不可拆分，前导零仍是十进制。`- 9223372036854775808`、`(-9223372036854775808)` 合法；`-(9223372036854775808)` 中正幅值非法，在执行前拒绝。对已合法最小值再取负，如 `-(-9223372036854775808)`，则是实际执行时的整数溢出（D71）。

Float64 字面量允许舍入、下溢及归零，溢出到非有限值报错。十进制浮点字面量与 float/try_float 的文本解析统一取最近的 Float64 值，恰好位于两个值中间时，选择最低有效二进制位为偶数的值（D72）；显示及回读细则见第 9.2 节。〔D05、D08、D62、D63、D71–D72〕

## 3. 文法（EBNF）

### 3.1 记法与适用范围

引号中是 MYB 符号；逗号连接产生式；`[ ... ]` 表示可选，`{ ... }` 表示重复零次或多次，`|` 表示选择。IDENT、INT、FLOAT、STRING 分别表示前节规定的标识符和字面量词法单元。

下列 EBNF 描述语句与表达式的组合形状，还须同时满足第 3.3 节和后续章节的上下文、名称及值约束。D71 已确认空块、空函数体、零字段结构及对应空构造，零次重复具有实际含义；带括号的赋值目标和最小整数直接负号例外亦按 D71 补齐。本文文法与配套语义已随整份规范获得用户整体确认。

### 3.2 产生式

```ebnf
program         = { top_item } ;
top_item        = function_decl | struct_decl | statement ;

function_decl   = "fn", IDENT, "(", [ parameters ], ")", block ;
parameters      = IDENT, { ",", IDENT } ;
struct_decl     = "struct", IDENT, "{", { field_decl }, "}" ;
field_decl      = IDENT, ":", type_ref, ";" ;
type_ref        = IDENT, [ "?" ] ;

block           = "{", { statement }, "}" ;
statement       = let_decl | assignment | expression_stmt | block
                | if_stmt | while_stmt | for_stmt
                | return_stmt | break_stmt | continue_stmt ;
let_decl        = "let", IDENT, [ "=", expression ], ";" ;
assignment      = expression, "=", expression, ";" ;
expression_stmt = expression, ";" ;
if_stmt         = "if", "(", expression, ")", block,
                  [ "else", ( if_stmt | block ) ] ;
while_stmt      = "while", "(", expression, ")", block ;
for_stmt        = "for", "(", "let", IDENT, "in", expression, ")", block ;
return_stmt     = "return", [ expression ], ";" ;
break_stmt      = "break", ";" ;
continue_stmt   = "continue", ";" ;

expression      = logical_or ;
logical_or      = logical_and, { "||", logical_and } ;
logical_and     = comparison, { "&&", comparison } ;
comparison      = additive, [ compare_op, additive ] ;
compare_op      = "<" | "<=" | ">" | ">=" | "==" | "!=" ;
additive        = multiplicative, { ( "+" | "-" ), multiplicative } ;
multiplicative  = unary, { ( "*" | "/" | "//" | "%" ), unary } ;
unary           = ( "+" | "-" | "!" ), unary | postfix ;
postfix         = primary, { access } ;
access          = ".", IDENT
                | "[", expression, "]"
                | "[", [ expression ], ":", [ expression ], "]" ;
primary         = literal | named_call | constructor | array_literal
                | IDENT | "(", expression, ")" ;
literal         = INT | FLOAT | STRING | "true" | "false" | "null" ;
named_call      = IDENT, "(", [ arguments ], ")" ;
arguments       = expression, { ",", expression } ;
array_literal   = "[", [ arguments ], "]" ;
constructor     = IDENT, "{", [ field_initializers ], "}" ;
field_initializers = field_initializer, { ",", field_initializer } ;
field_initializer = IDENT, ":", expression ;
```

### 3.3 必须配套的约束

- 赋值左侧只允许已有变量、数组元素或结构字段。产生式先描述表达式形状，再限定合法目标；赋值不是表达式，禁止链式赋值。最外层分组括号不改变目标可写性，不触发额外读取；`let x; (x) = 1;` 合法，仍先右后左。最终目标不能是切片或普通计算结果；中间接收对象的求值仍遵守普通访问规则，`(make_array()[0]) = value;` 仍可按数组写入检查。
- IDENT 作为表达式只表示读取普通变量；函数/类型/内置名称不因此成为普通数据值。调用只使用名称，不加入方法调用或通用函数值调用后缀。
- 字段类型名称只能是 Int64、Float64、Bool、String、Array 或已登记结构名，可加一个 `?`。Null 未确认为字段基类型；nullable 字段使用 `T?`。
- return 只能处于函数体；break/continue 只能作用于当前函数内词法包围它们的循环。
- 形参不能重名；同作用域不能重复声明；类型和受保护名称按既有规则检查。
- 分支和循环头必须有圆括号，所有代码块有花括号。简单语句以分号结束；独立块、函数/结构声明、分支及循环结束的 `}` 后不额外加分号。
- 空块合法；空函数正常结束仍返回 null。零字段结构的每次空构造产生独立实例，身份比较及复制规则不变；有字段结构的空构造仍报缺字段。
- 逗号列表不接受尾随逗号；不提供独立空语句 `;`、切片步长、`+=`、`++`、`--`。连续的未支持运算符不能通过拆成多个一元符号绕过限制。
- INT 描述十进制整数词素，值域受第 2.3 节及 D71 的直接负号例外约束；EBNF 不额外接受独立超范围正整数字面量，也不能在处理中先拒绝合法的直接负最小值。

〔D14–D16、D27、D44–D45、D60–D64、D68–D69、D71〕

## 4. 值、数值与比较

### 4.1 值与动态绑定

基本值为 Int64、Float64、Bool、String、Null；复合值为 Array 和命名结构实例。Int64 是有符号 64 位整数，范围为 -9223372036854775808..9223372036854775807；Float64 是二进制 64 位浮点数。Bool 的 true/false 不作为数值 1/0；null 是可读取的缺值，不是未初始化状态、0、false 或空字符串。

普通变量、函数形参及数组元素可以重新绑定不同类型，操作按实际值检查。普通赋值不根据旧值隐式转换右侧值。旧 D18 的固定变量类型转换规则已废止。

### 4.2 算术

- 数值混合算术允许 Int64 提升 Float64，可能舍入；数值与 String 之间不隐式转换。
- `/` 始终产生 Float64；`//`、`%` 严格接受两个 Int64。整数商向下取整，非零余数与除数同号，满足 `a = q * b + r`。
- `+` 用于数值相加或两个 String 拼接，不用于数组拼接；其他数值运算不接受 Bool。
- 一元 +/- 接受数值，! 接受 Bool。优先级按文法；同层算术左结合，一元右结合。
- 每一步实际整数运算都检查溢出。MIN // -1 报溢出，MIN % -1 正常得到 0。除零报错。
- 浮点允许舍入、下溢及归零；非有限运算结果报错，不通过 NaN/Infinity 值继续运行。
- 显式 Float64 转 Int64 向零截断并检查结果范围，不能与向下取整的整数除法混用。

### 4.3 相等、排序与逻辑

基本值按值相等；Array/结构按对象身份相等，不递归比较内容。不同类别不相等，唯 Int64/Float64 按数值比较，不能先将大整数有损提升而错误判断相等或顺序。Bool 与数值不同，null 仅与 null 相等；!= 是 == 的否定。

大小比较只接受数值组合或两个 String。字符串按 Unicode 码点字典序，前缀相同时较短字符串在前；其他排序组合报错。浮点比较不自动使用近似容差。

六种比较同层，禁止 `a < b < c` 等连续链写；显式圆括号可以分组比较结果。if/while 条件及逻辑操作数严格要求 Bool，不使用容器空/非空或数值零/非零的真假转换。

&&/|| 先求并检查左侧 Bool，按值短路，只有需要时才求并检查右侧，结果仍为 Bool。短路跳过执行及运行时检查，不能跳过源码语法和结构检查。〔D01–D09、D17–D20、D35、D39–D42、D56–D57、D63–D64〕

## 5. 名称、作用域与函数

let 显式建立名称；未声明赋值不自动创建变量。允许 `let x;`，读取未初始化绑定报错；给它赋值可完成初始化。

名称按词法作用域查找：当前块、本函数的外层块及参数、全局；不访问调用者局部变量。赋值更新最近可见的已有绑定，包含全局，无须 global 声明。找到未初始化绑定后不回退查找外层。

普通变量允许内层遮蔽，禁止同作用域重复声明。局部声明前仍查找外层；处理声明自身时，先建立新未初始化绑定再求初始值，因此 `let x = x + 1;` 读取新 x 而报错。

独立块建立词法作用域，块外不能读取其临时名称，外层赋值保留。可见范围结束不使仍被其他绑定引用的对象失效。函数参数与函数体最外层共用声明作用域，不能在该层再声明同名参数；内层块可遮蔽普通参数。

用户函数只有固定数量的位置参数，无参数/返回类型声明、默认参数、命名参数或可变参数。调用先检查目标与数量，再从左到右求实参，成功后进入函数体。形参建立独立局部绑定；重新赋值形参不修改调用者变量，修改共享对象内容可被调用者观察到。

`return value;` 返回实际值；`return;` 或正常到函数末尾返回 null。表达式语句丢弃结果，不作为隐式返回。运行错误向外传播，不能当作默认返回。

Array/结构实参和返回值不自动复制，函数内创建且返回的对象在调用结束后仍可使用。函数不是普通数据值，不能赋给变量、传参或作为返回值；首版不提供嵌套函数、闭包或重载。全局变量/函数/结构/内置名称不能重名。〔D16–D21、D29、D31、D43–D52、D61、D68–D69〕

## 6. 字符串、数组与数据访问

String 不可变，以 UTF-8 保存，长度/索引/遍历按 Unicode 码点，不按字节或字素簇。单个索引返回一个码点对应的 String，字符串不能通过索引或切片原地写入。

Array 可增长，元素混合类型，可嵌套 Array 或结构，不要求内层数组等长。单个索引读写不会自动追加。

接收对象长度为 n 时，单个索引合法范围是 `-n <= i < n`，负值换算为 n+i；否则报错。空序列没有合法单个索引。

普通切片左闭右开：默认起点 0、终点 n；负端点先加 n，再分别限制在 [0,n]。处理后 start >= end 返回空序列，不反向遍历；不接受第二个冒号。Array 切片新建外层槽位，内部对象仍共享；String 切片返回 String。

每次访问先计算并保留接收对象，再依次计算显式下标或起止端点，各一次；全部成功后检查接收对象、严格 Int64 下标/端点，并使用该原对象此时长度处理范围。变量在端点函数中改绑不更换接收对象，原对象经别名发生的合法修改会影响当前长度及内容。

非法接收对象也先完成下标/端点求值；表达式自身报错则停止后续求值。显式 null 不是省略端点。嵌套访问逐层进行，内层错误不再执行外层访问。〔D10–D13、D22–D29、D58、D69〕

## 7. 命名结构与共享

结构字段集合固定，不动态增删。字段声明类型默认不可空，`T?` 接受符合 T 的值或 null。Array 字段只检查是数组，不限制元素类型；命名结构字段只接受同名结构实例，不按字段相似性匹配。

构造使用 `Type { field: value }`，按字段名填写全部字段、各一次；未知/重复/缺失字段报错，可空字段也不能省略。首版无字段默认值或位置构造。

创建/写入时检查字段约束。Float64 字段接受 Int64 并提升；Int64 字段不接受 2.0 等浮点值，须显式转换。失败写入本身不替换目标，之前求值产生的副作用不回滚。

Array 和结构的普通赋值、传参和返回均共享对象，不自动复制。`b = a` 绑定同一个数组，`b = a[:]` 新建外层浅拷贝；两者不同。Array/结构字段写入已有可变对象同样共享，不复制；重绑某个普通名称不改变其他绑定。对象图允许共享、自循环和间接循环。

deep_copy 显式创建与原可变对象图隔离的副本，同时保留副本内部共享和循环；每个原可变对象在一次复制中对应唯一副本。基本值/String 保持值，结构保留类型。普通赋值和切片不隐式深拷贝。〔D28–D38、D42、D59–D61〕

## 8. 控制流与求值顺序

### 8.1 循环

if/else if/else 按条件选择分支；while 每轮重新求 Bool 条件。for 遍历 Array 或 String，source 表达式只求值一次，保留其对象，不创建隐式快照；来源变量改绑不更换遍历对象。

先在进入循环前的词法环境求 source，此时尚未引入循环变量，同名读取指向外层已有绑定。每轮取得当前元素后，建立循环变量绑定，与该轮循环体最外层共用声明作用域；同层不能再次 let 声明同名变量，非法重复声明按 D68 执行前拒绝，更内层块可以遮蔽。循环结束后循环变量不再可见，外层同名变量继续有效（D70）。

循环变量每轮绑定当前元素/码点 String。重绑循环变量不写回数组槽位；元素是可变对象时，修改其内容仍可见。允许替换数组已有元素，之后访问尚未访问位置时读取最新值。source 的来源求值先于循环变量绑定，不改变 D50 的普通 let 初始值求值规则；更深块中的同名 let 初始化仍按 D50。外层绑定在循环后继续有效不代表恢复旧值，source 或循环体已有副作用仍保留。

活动 for 遍历期间，任何别名、字段或函数参数都不能增删同一 Array；修改前报错。while 不自行建立该限制，也不能绕过外层活动 for 的限制。遍历浅拷贝数组可增删原数组，因两者外层对象不同。

break/continue 只影响当前函数内最内层循环。正常完成、break、return 或错误退出均结束该次活动遍历限制。

### 8.2 求值顺序

| 操作 | 顺序 |
|---|---|
| 普通二元表达式 | 左侧、右侧、检查并执行运算 |
| && / `\|\|` | 左侧求值并检查 Bool，必要时才求右侧 |
| let 初始化 | 先建立未初始化新绑定，再求初始值 |
| 普通赋值 | 完整右侧、左侧位置、检查并写入；不提供赋值表达式 |
| 函数/内置调用 | 目标及数量检查、从左到右求全部实参、内置值类型检查或进入用户函数体 |
| 数组字面量 | 元素从左到右求值 |
| 结构构造 | 类型/字段集合检查、按构造源码字段顺序逐项求值并检查 |
| 索引/切片 | 接收对象、显式下标/端点、检查并按原对象当前长度访问 |

任一步求值错误停止后续，不回滚已发生副作用。〔D40、D50、D53–D57、D64、D68–D70〕

## 9. 已确认的基础内置函数

所有接口均固定参数数量，沿用第 8.2 节调用规则。新增宿主实现不改变普通变量动态类型或函数调用语法。

| 接口 | 约定 |
|---|---|
| `len(value)` | Array 元素数或 String 码点数，返回 Int64 |
| `append(array, value)` | 末尾追加，返回 null |
| `insert(array, index, value)` | 在位置前插入，返回 null；位置为 Int64，非负 0..n，负 -n..-1 先加 n；空数组仅位置 0 |
| `pop(array)` | 删除并返回末元素，空数组报错 |
| `remove_at(array, index)` | 按单个 Int64 索引删除并返回元素 |
| `deep_copy(value)` | 按第 7 节显式复制 |
| `print(value)` | 按显示规则输出并换行，刷新 stdout，返回 null |
| `write(value)` | 同上但不加换行，仍刷新，返回 null |
| `read_line()` | 读取一行 UTF-8 标准输入，去 LF/CRLF，空行返回空串；正常 EOF 返回 null；无换行末行先返回内容；编码/读取失败报错 |
| `int(value)` | 接受 Int64/Float64/String；数值转换或严格十进制文本解析，失败报错 |
| `float(value)` | 接受 Int64/Float64/String；数值转换或严格十进制/小数/科学记数文本解析，失败报错 |
| `str(value)` | 按下述已确认显示规则返回 String |
| `try_int(text)` | 仅 String，解析内容/范围失败返回 null，错误参数类型或求值错误仍报错 |
| `try_float(text)` | 仅 String，解析内容/范围失败返回 null，下溢归零仍成功；不吞其他错误 |
| `assert(condition, message)` | 严格 Bool/String 两参数；真时无输出并返回 null，假时产生含 message 的断言错误；message 按普通实参规则求值 |
| `read_text(path)` | String 路径，整文件 UTF-8 读取，去开头一个 BOM，保留换行；空文件返回空串，失败报错 |
| `write_text(path, text)` | 两个 String，创建/覆盖 UTF-8 文件，不添加 BOM、不转换换行、不自动建父目录，成功返回 null |
| `split(text, separator)` | 两个 String，分隔符非空；从左到右精确不重叠拆分，保留空片段，返回新数组 |
| `join(parts, separator)` | Array 与 String，数组元素须全为 String，连接为字符串；空数组返回空串 |
| `trim(text)` | String，裁去首尾 ASCII 空白 U+0009..U+000D/U+0020，内部不变 |
| `split_lines(text)` | String，按 CRLF/LF 拆行，保留内部空行，末尾单个换行不额外制造空行；空串返回空数组，单独 CR 保留 |

数组增删接口对所有别名生效并遵守活动遍历限制；返回的元素不自动复制。文本函数不修改输入。

int/float 的文本解析先去首尾上述 ASCII 空白，允许前导正负号，要求完整匹配。int 不接受小数/指数，前导零为十进制；Float64 向 Int64 转换向零截断并检查范围。float 接受十进制整数文本或合法浮点形式，允许舍入/下溢，拒绝非有限值及溢出；float/try_float 文本解析与浮点字面量统一使用第 2.3 节的最近值、正中取偶规则（D72）。Bool/Null/Array/结构不接受 int/float 转换。

str/print/write 使用下文第 9.1–9.3 节同一套确定显示规则（D65/D72）；默认显示用于查看值，不由此增加序列化接口或文件数据格式。

文件路径支持中文，相对路径以启动解释器时工作目录为基准；正常返回前完成操作并关闭文件。写入失败可能已有部分副作用，不承诺原子替换或恢复。流式文件对象及多文件导入未因这些接口自动获批。〔D30、D58–D59、D65–D67〕

### 9.1 普通值、容器与字符串显示

str(value) 生成下述文本，print 输出同一文本再加一个换行，write 输出同一文本且不加换行。Int64 使用 ASCII 十进制数字，无正号或多余前导零；Bool/Null 分别为 true/false/null。Float64 见第 9.2 节。

| 类别 | 精确格式示例 |
|---|---|
| 空数组 | `[]` |
| 数组 | `[1, "你好", true, null]` |
| 嵌套数组 | `[[1, 2], [3, 4]]` |
| 非空结构 | `Point { x: 1, y: 2 }` |
| 零字段结构 | `Marker {}` |

数组元素或结构字段之间为逗号加一个 ASCII 空格，无尾随逗号。字段名后为冒号加一个空格。数组方括号内侧不额外加空格；非空结构的花括号内侧各一个空格；类型名与左花括号之间一个空格。默认不自动换行或省略元素。

结构按字段声明顺序显示，与构造填写顺序无关；此规则不改变 D64 按构造源码字段顺序进行求值的要求。

根 String 原样显示，不额外加引号或转义。出现在数组/结构内部的 String 统一带双引号，并按下列优先规则转义；对其他字符原样保留，不做 Unicode 规范化：

| 字符 | 嵌套字符串中的显示 |
|---|---|
| 双引号、反斜杠 | `\"`、`\\` |
| 换行、回车、Tab | `\n`、`\r`、`\t` |
| 除以上字符外的 U+0000..U+001F、U+007F..U+009F，以及 U+2028/U+2029 | `\u{...}`；十六进制小写，不加多余前导零，零写成 `\u{0}` |
| 其余字符 | 原样，包括中文、emoji 和单引号 |

因此 print("第一行\n第二行") 实际输出两行；print(["第一行\n第二行", "北邮😀"]) 输出一行，其内容为 `["第一行\n第二行", "北邮😀"]`。

### 9.2 Float64 的精确显示与回读

正零显示 `0.0`，负零显示 `-0.0`，保留符号。其他有限 Float64 值按以下规则显示：

1. 选取能按 MYB 第 2.3 节的 Float64 解析规则回读为原值的十进制表示，以有效数字数量最少为准，不按最终输出字符串长度比较。相同有效位数有多个候选时，取与原值精确数学距离最近者；仍相同时取末位十进制有效数字为偶数者。
2. 为决定记法，将所选非零绝对值的十进制表示规范化为 c × 10^q，其中 c 为无前导零和末尾零的正整数；若 c 有 n 位，科学指数 e = q + n - 1。e 必须来自最终选出的十进制表示，不沿用源码指数，也不根据二进制原值估算一个可能跨越边界的指数。
3. `-4 <= e < 16` 时使用定点形式，其他情况使用科学形式。负值在最终文本前添加负号；所有数字为 ASCII，十进制点固定为 `.`，不用千位分隔符。
4. 定点形式若没有小数部分，补 `.0`；否则不添加多余小数尾零。科学形式小数点前恰有一个非零数字，其余所选有效数字在小数点后，无多余尾零；有效数字只有一位时不加小数点，也不额外补 `.0`。
5. 科学形式使用小写 `e`，非负指数带 `+`，负指数带 `-`，指数不保留多余前导零。

| Float64 值 | 显示文本 |
|---|---|
| `1.0` | `1.0` |
| `1e3` | `1000.0` |
| `1e15` | `1000000000000000.0` |
| `1e16` | `1e+16` |
| `1e-4` | `0.0001` |
| `1e-5` | `1e-5` |
| 正零、负零 | `0.0`、`-0.0` |

回读指 float(str(x)) 得到同一 Float64 值，并保留零的符号。源码十进制浮点字面量与 float/try_float 的十进制文本解析统一按最近值、恰好居中时最低有效二进制位为偶数舍入；既定的下溢允许、溢出拒绝规则不变。本节不指定宿主格式化算法或新增格式化语法。〔D65、D72〕

### 9.3 循环对象与组合示例

仅在当前递归路径再次遇到同一个复合对象时，用 `<cycle>` 替代该次对象整体，不带字符串引号。自含数组显示 `[<cycle>]`。已从当前路径退出的共享对象可以再次展开；两个元素共享同一个 [1] 时显示 `[[1], [1]]`，不因别名共享显示循环标记。

```myb
struct Point {
    x: Int64;
    y: Int64;
}

let point = Point { y: 2, x: 1 };
let values = [point, "第一行\n第二行", 1.0];
append(values, values);

print(values);
```

按规则预期输出以下一行及其行尾换行：

```text
[Point { x: 1, y: 2 }, "第一行\n第二行", 1.0, <cycle>]
```

该结果来自阅读推导，尚未执行。显示不改变值的相等性、字段构造求值顺序、共享关系或复制行为。〔D56、D59、D64–D65、D72〕

### 12.1 对象共享与显式复制

struct Record {

### 12.2 数据处理与循环

```myb
struct Summary {
    count: Int64;
    total: Int64;
    invalid: Int64;
}

fn summarize(lines) {
    let count = 0;
    let total = 0;
    let invalid = 0;

    for (let line in lines) {
        let text = trim(line);
        if (text == "") {
            continue;
        }

        let value = try_int(text);
        if (value == null) {
            invalid = invalid + 1;
        } else {
            count = count + 1;
            total = total + value;
        }
    }

    return Summary { count: count, total: total, invalid: invalid };
}

let result = summarize(["10", " ", "bad", "20"]);
print(result);
```

按规则推导，空白行跳过，bad 为一条无效数据；输出一行 `Summary { count: 2, total: 30, invalid: 1 }`。返回的新实例在函数结束后仍有效；处理过程中不增删被遍历数组。此示例尚未执行。
